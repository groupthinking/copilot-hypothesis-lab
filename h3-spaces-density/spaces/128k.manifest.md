# Space Manifest — 128k (Very Rich Context)

## Metadata
- **Space ID**: `h3-128k`
- **Target Context Tokens**: ~128,000
- **Actual Context**: Full codebase + tests + docs + RFCs

## Purpose
Very rich context. Adds the full test suite, all documentation, and relevant RFC text to the 32k base. Tests whether extremely rich context continues to improve quality or whether diminishing returns have set in.

## Context Included

All of 32k, plus:

1. **Full test suite** — all unit and integration tests, ~40,000 tokens
   - Existing test patterns for the agent to match
   - Test fixtures, mocks, and helpers
2. **Full RFC 8628** (OAuth 2.0 Device Authorization Grant) — ~8,000 tokens
3. **Related RFCs** — RFC 6749 (OAuth 2.0 core), RFC 7636 (PKCE) excerpts — ~6,000 tokens
4. **API integration guides** — third-party OAuth provider docs — ~4,000 tokens
5. **Security audit reports** — past findings and fixes, ~3,000 tokens
6. **Architecture decision records (ADRs)** — relevant decisions, ~5,000 tokens
7. **Changelog and past PR descriptions** — for convention learning, ~10,000 tokens
8. **Issue history** — closed issues related to auth, ~10,000 tokens

**Total**: ~128,000 tokens

## What the Agent Knows

Everything from 32k, plus:
- Complete test patterns to exactly match
- Full OAuth2 device flow RFC including all edge cases
- Related security considerations from PKCE RFC
- How past security issues were resolved
- All architectural decisions affecting auth

## Hypothesis Role

This is the **expected knee-region** data point. The hypothesis predicts quality gains should decelerate significantly between 32k and 128k as the core information has already been provided and additional context is redundant.

The inflection point is predicted to fall somewhere between 32k and 128k.
